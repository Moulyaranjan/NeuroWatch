ABOUT THE PROJECT

Research that stays grounded in real movement data.

NeuroWatch explores personalized movement monitoring and explainable drift analysis using wearable and inertial sensor data.

DATA PRIVACY

Your data stays local

Sensor recordings and personal datasets are handled by the local application. Do not commit private exports or device credentials to source control.

CURRENT CAPABILITIES

Evidence before interpretation

Live IMU payloads, session controls, CSV export, rolling feature means, and dashboard updates are provided by the existing API. Missing sensors and unavailable features remain clearly marked.
